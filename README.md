# Non-Motor Symptom Trajectories in Parkinson's Disease: A PPMI Cohort Study

## Overview
This repository contains the complete R code for the analysis of non-motor symptom trajectories in Parkinson's disease patients from the Parkinson's Progression Markers Initiative (PPMI) cohort.

**Corresponding author:** Wen Zhou (zhouwen611@126.com)

## Requirements
- R version 4.2.2 or higher
- Key packages: lcmm (≥ 2.0.0), ggplot2 (≥ 3.4.4), dplyr (≥ 1.1.3), mice (≥ 3.15.0), forestplot (≥ 3.1.0), patchwork (≥ 1.1.2)

## Data Access
This analysis uses de-identified data from the PPMI database. Data are available upon request at:
https://www.ppmi-info.org/access-data-specimens/download-data

**Important:** Due to data use agreements, the original PPMI data are NOT included in this repository. Users must register on the PPMI website, sign a Data Use Agreement, and download the data directly from PPMI.
